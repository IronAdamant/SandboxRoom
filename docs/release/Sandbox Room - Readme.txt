SANDBOX ROOM - by Deadmansprice
A clean, up-to-date testing facility for Fallout 4, reached by holotape.

GETTING THERE
A few seconds after you leave Vault 111 (or shortly after loading an existing save), the (Sandbox Room) Holotape
is added to your inventory. Play it from the Pip-Boy:
  Teleport In   remembers exactly where you are and takes you to the Sandbox Room
  Teleport Out  takes you back to exactly where you were, with everything you are carrying
Console: coc SandboxRoom (no return point that way).

WHAT'S INSIDE
- Main hall: crafting stations (weapons, armour, chemistry, cooking, power armour with three empty frames) and
  signed storage cabinets that never run out (Weapons & Ammo, Apparel, Mods, Power Armor, Aid, Miscellaneous).
- Target range: four walled bays of holographic targets that stand still, never fight back and give no XP.
  Each bay's terminal sets the target, its health and its armour. Shooting galleries at two heights.
- Arena: pick an enemy, then how many (1-10). Enemies stay frozen until you walk in, and freeze again when you
  leave. Balconies at two heights. Kill or remove everything spawned from the terminals.

PLAYING FAIR
Everything in the room is free. Save before you teleport in, and load that save if you don't want to keep what
you took.

INSTALLATION
Mod manager: install the archive; it installs the core files and offers the add-ons for the DLC you own.
Manual: copy Sandbox Room.esp, Sandbox Room - Main.ba2 and Sandbox Room - Textures.ba2 into Fallout 4\Data,
plus Sandbox Room - <DLC>.esp for each DLC you own. Enable the plugins. Never install an add-on for a DLC you
don't own.

REQUIREMENTS
Fallout 4 (current version). No F4SE. DLC optional. All plugins are light plugins (ESL).

UNINSTALLING
Teleport out first and use "Remove everything spawned" on the arena terminals. Keep a save from before you
installed the mod.
