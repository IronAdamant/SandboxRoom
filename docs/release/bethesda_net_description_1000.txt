A clean testing facility, reached by holotape. No F4SE. Requires all DLC.

Shortly after you get the Pip-Boy (alternative starts too), the (Sandbox Room) Holotape is added. Teleport In takes you to the room; Teleport Out returns you where you were.

- Crafting stations, robot workbench, Nuka-Mixer, power armour station with 3 frames.
- Storage cabinets that never run out, base game and every DLC.
- Target range: holographic targets that stand still and give no XP. Set health (up to 100,000) and armour.
- Arena: base game and DLC enemies, 1-10 at a time. Frozen until you walk in; they can't follow you out.
- NEW Perks & Stats: S.P.E.C.I.A.L., perks, perk points, level, faction relations.
- NEW Hack and Lock Practice: locks and terminals, Novice to Master, that relock after every try.

Playing fair is up to you: save before teleporting in.

Own interior cell, no vanilla records edited. Light plugin.
